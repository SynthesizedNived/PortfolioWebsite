HTML CSS

HTML (HyperText Markup Language) and CSS (Cascading Style Sheets) are the fundamental technologies used to create and design websites. HTML is used to structure the content of a webpage using elements such as headings, paragraphs, links, images, sections, lists, and navigation menus, while CSS is used to control the visual appearance and layout of those elements. I use HTML and CSS to build websites, create responsive layouts, design navigation systems, develop dropdown menus, arrange content using Flexbox and Grid, and create consistent visual themes. Through working with HTML and CSS, I have developed an understanding of semantic structure, classes and IDs, spacing, typography, colors, borders, positioning, Flexbox, CSS Grid, hover effects, transitions, and responsive design. Working with these technologies has also helped me understand how the structure of a webpage and its visual presentation work together to create an interactive and user-friendly website.
