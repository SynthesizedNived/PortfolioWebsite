Blender

Blender is a powerful open-source 3D creation software used for 3D modelling, animation, rendering, visual effects, simulation, and game development. It provides a wide range of tools for creating and manipulating 3D objects, environments, characters, materials, lighting, and animations. Blender supports techniques such as polygon modelling, sculpting, UV mapping, texturing, rigging, and rendering, making it useful for both creative and technical projects. I use Blender mainly for creating 3D models, game assets, environments, and experimenting with different forms of 3D design. Through working with Blender, I have developed an understanding of 3D modelling workflows, object transformation, materials, lighting, basic texturing, and preparing 3D assets for use in other applications such as game engines.
