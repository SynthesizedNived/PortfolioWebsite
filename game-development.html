Game Development

Game development is the process of designing, creating, and developing interactive games using programming, game engines, digital assets, audio, and visual design. It combines different areas such as programming, game mechanics, level design, 3D modelling, animation, user interfaces, and sound to create an interactive experience. I use game development tools such as Godot to experiment with different game ideas, create gameplay mechanics, design levels, and work with 2D and 3D assets. Through working on game development projects, I have developed an understanding of scenes, nodes, game objects, player input, physics, collisions, scripting, level design, and basic game logic. Working on games has also helped me improve my problem-solving skills and understand how programming, design, and interactive elements work together to create a complete game.
