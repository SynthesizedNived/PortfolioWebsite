3D Modelling

3D modelling is the process of creating three-dimensional objects and environments using specialized software. It involves creating the shape and structure of an object, refining its geometry, applying materials and textures, and preparing it for rendering, animation, or use in applications such as games and simulations. I use 3D modelling to create objects, environments, game assets, and other digital designs, mainly working with tools such as Blender. Through working with 3D modelling, I have developed an understanding of basic modelling techniques, object transformations, meshes, vertices, edges and faces, materials, lighting, UV mapping, and basic texturing. It has also helped me understand how optimized and properly structured 3D assets can be created for use in game engines and other digital projects.
